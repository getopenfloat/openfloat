Discover skins, bid in auctions and buy or sell at a fixed price. OpenFloat is a marketplace we are building in the open.

## Why OpenFloat?

- **Open source:** A marketplace others can learn from and build on.
- **Made for collectors:** Find items by float, paint seed, exterior and more.
- **Accessible:** Create a local inventory or import from Steam. Steam is optional.

## Status

OpenFloat is in early development. The marketplace is not live yet, and these features are planned. Star the repo to follow along, or explore the [project documentation](https://github.com/getopenfloat/documentation).
